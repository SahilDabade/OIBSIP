### 3. Level 1 · Task 3: THERMO — Smart Temperature Converter
A futuristic, dark glassmorphic temperature conversion web application designed at the intersection of weather technology and telemetry SaaS.
* **Location**: [`LEVEL 1/Task-3-Temperature-Converter`](LEVEL%201/Task-3-Temperature-Converter/)
* **Technologies**: Semantic HTML5, Vanilla CSS3, Modular Vanilla JavaScript (ES6+).
* **Brand & Visuals**: **THERMO** (*"Experience Temperature Differently"*), frosted glass cards (`backdrop-filter: blur(20px)`), aurora gradient mesh.
* **Key Features**:
  * **Simultaneous Tri-Scale Computation**: Real-time conversions across Celsius (°C), Fahrenheit (°F), and Kelvin (K).
  * **Strict Thermodynamic Bounds**: Rejects physically anomalous inputs below Absolute Zero ($-273.15^\circ\text{C}$, $-459.67^\circ\text{F}$, $0\text{ K}$).
  * **Environmental Thermal Spectrum**: Interactive horizontal scale dividing temperatures into 5 human sensation zones (*Freezing*, *Cool*, *Comfortable*, *Warm*, *Hot*) with an active gliding needle pointer.
  * **Adaptive 4-Decimal Precision**: Strips trailing zeros automatically.
  * **Desktop Hero HUD**: Animated futuristic SVG gauge with real-time synchronized data chips.
  * **Conversion Snapshot History**: Persists last 5 calculations in `localStorage` with 1-click reload.
* **How to Run**:
  Open [`LEVEL 1/Task-3-Temperature-Converter/index.html`](LEVEL%201/Task-3-Temperature-Converter/index.html) in any browser.

## 💻 Local Execution & Preview

No build steps, compilers, or package manager installations are required.

### Method 1: Instant Direct Launch
Double-click `index.html` inside any project folder to open directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

### Method 2: Local HTTP Server (Python)
Run a local development server from the repository root:
```bash
# Python 3
python -m http.server 8080
```
Then navigate to:
* Task 1: `http://localhost:8080/LEVEL%201/Task-1-AI-SaaS-Landing-Page/`
* Task 2: `http://localhost:8080/LEVEL%201/Task-2-Personal-Portfolio/`
* Task 3: `http://localhost:8080/LEVEL%201/Task-3-Temperature-Converter/`

### Method 3: Node.js Serve
```bash
npx serve .
```
